# Case folder contents

One Drive folder per patient, named `NPO <initials>` (for example `NPO X.Y.`).
The agent writes the draft report into the same folder.

| File | Required | What the agent uses it for |
|---|---|---|
| `Intakegesprek.docx` | yes | Raw notes of the (hetero)anamnesis in her headings (PROBLEEMSTELLING, COGNITIEVE KLACHTEN, TIJDSVERLOOP, SOCIALE SITUATIE, OPLEIDING/BEROEP, GEDRAGSMATIGE / EMOTIONELE KLACHTEN, ANDERE, MEDISCHE VOORGESCHIEDENIS). **Must include sex, age and education**, and ideally referrer, date of consultation and handedness. |
| `Testonderzoek <initials>.pdf` | yes | Scan of all score forms and drawings (AVLT, Bourdon, Tower, CFT + drawings, COWAT, WAIS responses, VAT, Kubus-Klok). Also the source of handwritten observations. |
| `Normen.xlsx` | yes | Her scoring workbook with this patient's entries (`Scorehulpmiddel`, `Bourdon_invul` row times). |
| `BDI-II-NL.xlsx` | if administered | BDI-II item scores |
| `SCL-90_vragenlijst.xls` | if administered | SCL-90 item scores and subscale totals |
| `Observaties.docx` | optional | Her own observations and impression, if written separately |

Tip for her: add a line such as `Man, 53 jaar, opleiding ≤ 12 j` at the top of
the intake notes. The agent then never needs to ask.
